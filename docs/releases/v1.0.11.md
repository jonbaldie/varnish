# v1.0.11

## Features

- Add `/start.sh --check`, which validates the runtime settings, renders the backend configuration, and compiles the selected VCL without starting Varnish. It cannot be combined with `VARNISH_START`.
- `/start.sh` now accepts no arguments or the single `--check` argument; unknown arguments fail with an error instead of being ignored.

## Tests

- Give the bug-finding campaign's startup and stress phases a checked runtime-health interface. Counters are read from `varnishstat` and never defaulted, and the campaign exits non-zero when it cannot measure Varnish. This fixes a collector that never read a counter, so it always reported 0 panics and restarts.

## Verification

- `COMPOSE_PARALLEL_LIMIT=1 make -j1 test test-e2e-hard`
