# v1.0.12

## Fixes

- Validate storage methods (`VARNISH_STORAGE`) and extra arguments (`VARNISH_EXTRA_ARGS`) during `/start.sh --check` by passing `-s` and extra options to `varnishd -C`, catching misconfigurations during preflight without starting Varnish.
- Invalidate cached targets referenced by relative-path `Location` and `Content-Location` response headers on unsafe HTTP methods by resolving relative references against the request path and reducing dot segments.
- Keep cached deflate responses on a separate cache object (`hash_data("deflate")`) so deflate content is not inadvertently served to clients that do not accept deflate.

## Tests

- Give campaign phases a checked execution and reporting boundary (`PhaseResult`), writing `report.json` atomically across phase transitions and persisting failures and HTTP evidence even when an exception occurs.
- Tighten campaign report assertion polling window to avoid a race condition when killing Varnish during transport failure tests.

## Verification

- `COMPOSE_PARALLEL_LIMIT=1 make -j1 test test-e2e-hard`
